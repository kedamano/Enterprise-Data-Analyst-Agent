# RAG 合成语料 Benchmark（Offline）

> 全程 offline，hashing trick 64-dim 嵌入 + BM25 + RRF + 项目既有 deterministic reranker。

- 语料规模：60 条短文档，6 个主题
- 查询数量：12 条（每条 2-5 个相关文档，人工标注 ground truth）

## 结果

| Metric   | Score |
|----------|-------|
| Recall@1 | 37.5% |
| Recall@3 | 68.1% |
| Recall@5 | 75.0% |
| MRR      | 0.92  |
| Duration | 6ms |

## 解读

Recall@1 为 37.5%，说明Top-1 直接命中相关文档的查询占比；Recall@3 = 68.1%、Recall@5 = 75.0%，表明在 5 窗口内几乎所有查询都能覆盖至少一条 ground-truth 文档。MRR = 0.92 反映平均倒数排名，越接近 1 说明正确答案越靠前。本 benchmark 使用 hashing trick 嵌入（非语义模型），纯字面重合为主的 query 分数会偏高，实际生产使用 sentence-transformers 后同义改写场景的 recall 会有所衰减，建议以数值模型语义向量作为上线基线。
